# ISRO Satellite Data Explorer

## Project Overview
ISRO Satellite Data Explorer is an educational Python application that compares two images captured at different times and visualizes their pixel-level differences.

## Features
- Upload an earlier and a later image
- Display and compare images
- Generate a visual difference map
- Calculate an average pixel-difference score

## Technologies Used
- Python
- Streamlit
- NumPy
- Pillow (PIL)

## Installation and Setup
1. Clone or download this repository.
2. Install the required packages:

   `python -m pip install -r requirements.txt`

3. Run the application:

   `python -m streamlit run app.py`

4. Open the local URL displayed in the terminal.

## Limitations
This is an educational prototype. Pixel differences do not directly measure actual land-cover change. Meaningful satellite analysis requires geographically aligned and appropriately processed imagery.
